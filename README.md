# WE-Mender

Wallpaper Engine（Steam 创意工坊，appid 431960）**“三账”诊断与修复工具**。

壁纸依赖三处数据一致：**订阅清单**（云端镜像）、**账本安装记录**（acf）、**硬盘文件夹**（事实）。任何一处不同步就会出现壁纸黑屏、反复重下、整库被判未安装等故障——WE-Mender 把三账对齐，八种状态逐一诊断，修复动作全程备份可回滚。

## 下载

到 [**Releases**](https://github.com/Supermikeka/WE-Mender/releases) 下载 `WE-Mender.exe`（单文件，双击即用，无需安装 Python）。

## 功能速览

- **一键排查**（全程只读）：三账状态差异卡、无主文件夹、损坏工程、体积统计
- **自动修复**：补录漏登记录 / 清理残留记录（备份 → 逐字节校验 → 原子写入 → 失败自动回滚）
- **单条动作**：清账本记录 · 转本地壁纸 · 删除到回收站 · 重新订阅跳转
- **哨兵监控**：8 秒心跳比对三账指纹，检测到变化自动轻量刷新
- **安全守卫**：空清单规模校验、条目数对账、复活检查、多库检查、清空段拦截——宁可拒绝，绝不误删
